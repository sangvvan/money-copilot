# Pull Request Approval Gate

A milestone PR is ready for human review only when:

- Scope matches the active milestone.
- Required automated tests pass.
- Security review has no unresolved blocking findings.
- QA maps evidence to every acceptance criterion.
- No secrets or real financial data are present.
- Documentation contains local verification steps.
- The PR describes risks and known limitations.

Agents must not merge the PR. Final merge belongs to the repository owner.
